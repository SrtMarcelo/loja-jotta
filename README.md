Loja Jotta 
Este repositório contém o código-fonte de uma página web desenvolvida para uma loja de varejo, focada em proporcionar uma experiência de navegação limpa, moderna e responsiva para os clientes.

Demonstração Online
Você pode acessar o projeto em funcionamento através do link:
👉 https://srtmarcelo.github.io/loja-jotta/

Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias essenciais para o desenvolvimento web front-end:

HTML5: Estruturação semântica das páginas e elementos da loja.

CSS3: Estilização visual, design responsivo e organização de layout.

JavaScript: Dinamismo e interatividade da interface.

Git e GitHub: Controle de versão e hospedagem do código-fonte e da página web (GitHub Pages).

 Estrutura do Projeto
index.html: Página principal da aplicação.

Arquivos de estilização (CSS) e scripts de comportamento (JavaScript).

Recursos visuais, imagens e componentes utilizados no layout da loja.

Como Executar o Projeto Localmente
Se você deseja clonar e testar este repositório em sua máquina, siga os passos abaixo:

Clone o repositório:

Bash
git clone https://github.com/srtmarcelo/loja-jotta.git
Abra a pasta do projeto no seu editor de código preferido (como o VS Code).

Execute a aplicação:

Abra o arquivo index.html diretamente em seu navegador web, ou utilize uma extensão como o Live Server no VS Code para visualizar as alterações em tempo real.
